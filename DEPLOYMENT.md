# Artifact Lens — Deployment Guide

## Overview

This document covers deploying Artifact Lens to production with:
- **Database**: Neon (PostgreSQL)
- **Backend API**: Render (Docker)
- **Frontend**: Vercel (Static Site)
- **3D Engine**: Modal/RunPod (GPU) or Colab (free)
- **LLM**: Ollama local / Together.ai / Fireworks

---

## 1. Database Setup (Neon)

### Create Neon Project

1. Go to [console.neon.tech](https://console.neon.tech)
2. Create new project: `artifactlens`
3. Choose region closest to your Render region (e.g., `us-east-1`)
3. Copy the connection string:
   ```
   postgresql://user:password@ep-xxx.region.neon.tech/artifactlens?sslmode=require
   ```

### Run Migrations

```bash
# Local
DATABASE_URL="postgresql://user:pass@ep-xxx.neon.tech/artifactlens?sslmode=require" npm run db:init

# Or from Render shell after deploy
```

## 2. Backend Deployment (Render)

### Option A: Render Blueprint (Recommended)

1. Push repo to GitHub
2. In Render dashboard: **New** → **Blueprint**
3. Connect GitHub repo
4. Render detects `render.yaml` and provisions:
   - PostgreSQL database (`artifactlens-db`)
   - Web Service (`artifactlens-api`)
   - Static Site (`artifactlens-frontend`)

### Option B: Manual Render Setup

#### Create PostgreSQL Database
1. Render Dashboard → **New** → **PostgreSQL**
2. Name: `artifactlens-db`
3. Plan: Free (or Starter)
4. Save connection string

#### Create Web Service (API)
1. **New** → **Web Service**
2. Connect GitHub repo
3. Settings:
   - **Runtime**: Docker
   - **Dockerfile Path**: `./Dockerfile`
   - **Build Command**: (auto from Dockerfile)
   - **Start Command**: (auto from Dockerfile)
   - **Port**: 3000
   - **Health Check Path**: `/health`

#### Environment Variables (Render Dashboard → Environment)
```
NODE_ENV=production
PORT=3000
DATABASE_URL=<from Neon connection string>
JWT_SECRET=<auto-generated or your secret>
JWT_EXPIRY=7d
OWNER_EMAIL=your@email.com
OLLAMA_BASE_URL=https://api.together.xyz/v1
OLLAMA_MODEL=meta-llama/Llama-3.2-11B-Vision-Instruct-Turbo
HUNYUAN_BASE_URL=https://your-3d-engine.modal.run
```

#### Build & Deploy
- Render builds Docker image automatically
- First deploy takes 5-10 minutes
- Subsequent deploys are faster (layer caching)

## 3. Frontend Deployment (Vercel)

### Connect Repository

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import GitHub repository
3. **Root Directory**: `client`
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`

### Environment Variables (Vercel Dashboard → Settings → Environment Variables)

```
VITE_API_URL=https://your-api.onrender.com
```

### Deploy
- Vercel builds and deploys automatically on push to main
- Preview deployments for PRs
- Custom domain configurable in Settings → Domains

## 4. Database Connection (Neon ↔ Render)

### Option A: Neon → Render (Recommended)

1. Neon connection string uses `sslmode=require`
2. Render Web Service can connect directly to Neon
3. No additional networking needed

### Option B: Render Managed PostgreSQL (Alternative)

If using Render's managed PostgreSQL instead of Neon:
1. Create Render PostgreSQL database
2. Use internal connection string: `postgresql://user:pass@db:5432/artifactlens`
3. Update `DATABASE_URL` in Render Web Service env vars

## 5. 3D Engine (Hunyuan3D) - GPU Required

### Option A: Modal (Recommended - Serverless GPU)

```python
# deploy_hunyuan.py
import modal

app = modal.App("artifactlens-hunyuan")

image = (
    modal.Image.debian_slim()
    .pip_install("torch", "torchvision", "fastapi", "uvicorn", "pillow", "trimesh")
    .run_commands(
        "git clone https://github.com/Tencent/Hunyuan3D-2.git /opt/Hunyuan3D-2",
        "pip install -r /opt/Hunyuan3D-2/requirements.txt"
    )
)

@app.function(
    image=image,
    gpu="T4",  # or A10G for faster
    timeout=600,
    container_idle_timeout=300,
)
@modal.web_endpoint(method="POST")
def generate(request: dict):
    from hy3dgen.shapegen import Hunyuan3DDiTFlowMatchingPipeline
    import base64, io
    from PIL import Image
    
    pipe = Hunyuan3DDiTFlowMatchingPipeline.from_pretrained("tencent/Hunyuan3D-2mini")
    
    frames = []
    for item in request["images"]:
        raw = base64.b64decode(item["image"].split(",").pop())
        frames.append(Image.open(io.BytesIO(raw)).convert("RGB"))
    
    mesh = pipe(image=frames[0])[0]
    buf = io.BytesIO()
    mesh.export(buf, file_type="glb")
    return Response(buf.getvalue(), media_type="model/gltf-binary")

# Deploy: modal deploy deploy_hunyuan.py
# Returns URL: https://your-name--artifactlens-hunyuan.modal.run
```

Deploy:
```bash
modal deploy deploy_hunyuan.py
# Copy URL → set HUNYUAN_BASE_URL in Render env vars
```

### Alternative: RunPod / RunPod Serverless

1. Create RunPod account
2. Deploy template: `tencent/Hunyuan3D-2mini` on T4/A10G
3. Get endpoint URL → set as `HUNYUAN_BASE_URL`

### Free Option: Google Colab + ngrok

See [Colab setup in README](./README.md#3d-engine-hunyuan3d-2-optional)

## 7. File Storage (GLB Models)

### Option A: Cloudflare R2 (Recommended - Free tier generous)

```bash
# Create R2 bucket: artifactlens-models
# Create API token with R2 read/write
# Add to Render env vars:
R2_ACCOUNT_ID=xxx
R2_ACCESS_KEY_ID=xxx
R2_SECRET_ACCESS_KEY=xxx
R2_BUCKET=artifactlens-models
R2_PUBLIC_URL=https://pub-xxx.r2.dev
```

### Option B: Cloudflare R2 via S3 API (S3-compatible)

```python
import boto3
s3 = boto3.client(
    's3',
    endpoint_url='https://<account_id>.r2.cloudflarestorage.com',
    aws_access_key_id=ACCESS_KEY,
    aws_secret_access_key=SECRET_KEY
)
s3.upload_fileobj(file_obj, 'artifactlens-models', f'{scan_id}.glb')
```

## 9. Deployment Checklist

### Pre-Deploy
- [ ] Neon project created, connection string saved
- [ ] GitHub repo connected to Render
- [ ] `render.yaml` in repo root
- [ ] `vercel.json` in `client/` folder
- [ ] `.env.example` has all required vars
- [ ] `docker-compose.yml` and `Dockerfile` in repo root

### Deploy Steps
1. **Push to GitHub** → Triggers Render build
2. **Wait for Render build** (5-10 min first time)
2. [ ] Render shows **Live** status
3. [ ] Add `VITE_API_URL` to Vercel env vars
4. [ ] Deploy frontend to Vercel
4. [ ] Test API health: `https://your-api.onrender.com/health`
5. [ ] Test frontend: `https://your-app.vercel.app`
5. [ ] Run `npm run demo:prepare` locally (warms model)

## 14. Troubleshooting

| Issue | Fix |
|-------|-----|
| API 502/504 | Check Render logs, increase timeout |
| DB connection failed | Check Neon IP allowlist (0.0.0.0/0) |
| 3D engine timeout | Increase Modal timeout, check GPU memory |
| Frontend 404 on refresh | Add Vercel rewrite rule |
| CORS errors | Check API CORS config, VITE_API_URL |
